Arquitectura Premium

Flujo SSO multitenant Smart3AI

  1. 1. El usuario accede con cuenta central (felipe@smart3ai.com).
  2. 2. AdminApps valida password + 2FA y emite JWT firmado.
  3. 3. El token incluye claims de organización, rol y audiencia.
  4. 4. Cada backend sincroniza contexto local y aplica tenant scope.
  5. 5. Nginx enruta por subdominio para una experiencia unificada.

Claims críticos en el token

{
  "iss": "https://sso.smart3ai.local",
  "aud": ["smart3ai-portfolio"],
  "organization_id": "",
  "role": "org_admin",
  "email": "felipe@smart3ai.com"
}
